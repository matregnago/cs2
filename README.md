# My Counter-Strike 2 Server Config

This is my personal config for running pug servers with skins.
To manage your skins and inventory: https://inventory.cstrike.app/

You can check if the server is broken [here](https://github.com/ianlucas/cs2-signatures) and if **CounterStrikeSharp** does not have a green tick in the linux column, the server will not work and you need to wait for an update.
